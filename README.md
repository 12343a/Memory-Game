# Memory Game

A fun and challenging memory game built with HTML, CSS, and JavaScript. Test your memory skills by remembering and repeating sequences of colored buttons!

## Features

- Interactive colored buttons (Red, Yellow, Green, Purple)
- Increasing difficulty as the sequence gets longer
- Simple and intuitive gameplay
- Responsive design

## How to Play

1. Open `memory.htm` in your web browser.
2. Press any key to start the game.
3. Watch the sequence of button flashes.
4. Repeat the sequence by clicking the buttons in the correct order.
5. If you get it right, the sequence gets longer. If you make a mistake, the game restarts.

## Technologies Used

- HTML5
- CSS3
- JavaScript (Vanilla)

## Files

- `memory.htm`: The main HTML file
- `memory.css`: Stylesheet for the game
- `memory.js`: JavaScript logic for the game

## Running the Game

Simply open `memory.htm` in any modern web browser. No additional setup required!
